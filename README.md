# Circulation Pump

Prosta integracja Home Assistant do sterowania pompką cyrkulacji ciepłej wody.

## Funkcje
- Wybierasz jedną pompę
- Wybierasz do 10 urządzeń wyzwalających (światła / switch'e)
- Ustawiasz czas działania i czas blokady
- Konfiguracja w pełni przez UI

## Instalacja przez HACS
1. HACS → Integracje → trzy kropki → **Custom repositories**
2. Wklej adres tego repozytorium
3. Kategoria: **Integration**
4. Pobierz integrację i zrestartuj Home Assistant
5. Ustawienia → Urządzenia i usługi → Dodaj integrację → **Circulation Pump**
